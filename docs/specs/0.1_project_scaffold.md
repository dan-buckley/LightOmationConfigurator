## Purpose

Establish the project directory structure, Docker environment, and development tooling so that all subsequent modules have a consistent, reproducible base to build on.

## Responsibilities

- Define the top-level directory layout for backend, frontend, docs, and data
- Provide a `docker-compose.yml` that starts the backend, frontend, and any supporting services
- Provide individual `Dockerfile` for backend and frontend
- Provide a `.env.example` with all required environment variables documented
- Provide a `.gitignore` appropriate for a Python + React + Docker project
- Support running the backend directly (outside Docker) for local development
- Provide a basic health check endpoint on the backend confirming the service is up

## Out of Scope

- Database schema creation (Module 0.2)
- Any application logic or API routes beyond a health check

## Inputs

- Developer machine (Mac or Windows) with Docker Desktop installed

## Outputs

- Running backend service accessible at a configured local port (e.g. `http://localhost:8000`)
- Running frontend service accessible at a configured local port (e.g. `http://localhost:3000`)
- `GET /health` returns `200 OK` with service status
- All environment variables documented in `.env.example`

## Key Rules and Constraints

- All configurable values (ports, database path, CORS origins) must be read from environment variables
- The backend must start cleanly even if the database file does not yet exist
- Docker Compose must use a named volume for the SQLite database file so data persists across container restarts
- Hot-reload must be enabled in development mode for both backend and frontend

## Acceptance Criteria

- [ ] `docker compose up` starts both services without errors
- [ ] `GET http://localhost:8000/health` returns `200 OK`
- [ ] Frontend loads at `http://localhost:3000`
- [ ] Stopping and restarting Docker does not lose the database file
- [ ] Backend can be started outside Docker using `uvicorn` for local development
- [ ] `.env.example` documents every required variable
