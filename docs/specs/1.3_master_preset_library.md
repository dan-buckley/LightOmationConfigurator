# 1.3 Master Preset Library

| Field | Detail |
|---|---|
| ID | 1.3 |
| Layer | Data Management |
| Status | Backlog |
| Depends On | 0.4 |
| Milestone | M1 |

## Purpose

Provide a central store of reusable WLED preset templates. These are the source assets from which target light presets are generated. A master preset captures the intent and effect settings of a preset independently of any specific light's LED layout.

## Responsibilities

- Create, read, update, and delete master presets
- Categorise presets by type: Button, Playlist, Build, Standard, All-LED, Segmented
- Track where each preset came from (source light and original preset ID)
- Allow bulk import of presets from a stored `presets.json` import record
- Allow searching and filtering by name and category
- Manage preset categories

## Out of Scope

- Transposing or generating presets for a target light (Module 2.1 / 2.2)
- Assigning presets to a specific light (Module 1.4)

## Inputs

- User-entered preset name, category, raw preset JSON, notes
- Bulk import: reference to an `imported_files` record; user selects which presets to bring into the library

## Outputs

- Persisted records in `master_presets`
- Change log entries for all create/update/delete operations

## API Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/api/v1/presets` | List all master presets (filterable by category, search) |
| POST | `/api/v1/presets` | Create a master preset |
| GET | `/api/v1/presets/{id}` | Get a single master preset |
| PUT | `/api/v1/presets/{id}` | Update a master preset |
| DELETE | `/api/v1/presets/{id}` | Delete a master preset |
| POST | `/api/v1/presets/bulk-import` | Import selected presets from an imported file |
| GET | `/api/v1/presets/categories` | List all categories |

## UI Screens

- **Library browser** — filterable list of master presets with name, category, source light, and quick-action links
- **Preset detail / edit** — view and edit the preset name, category, raw JSON, and notes; source reference shown read-only
- **Bulk import screen** — select an imported `presets.json` record; shows a list of presets in that file; user ticks which ones to add to the library; previews the preset JSON before confirming

## Key Rules and Constraints

- A master preset's `preset_data` is the raw WLED preset JSON for that preset entry (the value from the `presets.json` object, keyed by preset ID)
- Deleting a master preset must warn if it is referenced by any light preset assignments
- Bulk import must not create duplicates if a preset with the same source light and source preset ID already exists in the library; user is informed
- Preset categories are fixed in the first version (no UI to create custom categories)

## Acceptance Criteria

- [ ] Can create a master preset manually with all fields
- [ ] Bulk import from RB Proto's stored `presets.json` shows the list of presets and allows selective import
- [ ] Imported presets appear in the library with correct source tracking
- [ ] Filtering by category returns only matching presets
- [ ] Deleting a preset that has assignments shows a warning with assignment count
- [ ] Duplicate detection prevents re-importing the same source preset
